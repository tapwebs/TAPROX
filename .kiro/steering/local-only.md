# TAPNETTRACK is a local-only project

This rule is set by the project owner and applies to every task in this workspace.

- Never push code to GitHub or any other remote Git host.
- Never add or configure a Git remote, create a pull request, publish the repository, or upload
  source code to any external service.
- Local Git commits and branches are allowed (version control and rollback). All development stays
  on this machine.
- Preserve existing commits and the working tree. Do not rewrite or discard history, and do not
  reset, clean or force anything unless the owner explicitly asks.
- When finishing a branch, offer only: merge locally, or keep the branch. Never offer push or PR.
- Do not include project source code or secrets in web searches, web fetches or any other outbound
  request. Downloading dependencies and documentation is fine.
